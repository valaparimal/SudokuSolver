# 🔢 Sudoku Solver

An interactive web-based **Sudoku Solver** built using **HTML, CSS, and JavaScript**.  
Allows users to enter their own puzzle and solve it instantly with visual feedback.

---

## 🎮 Features

- ✏️ **Manual input**: Fill any Sudoku puzzle grid with your own values
- 🔁 **Reload option**: Reset the board to try a new puzzle
- ✅ **Solve button**: Automatically solves the puzzle using backtracking
- ⚠️ **Error detection**: Shows a warning if the Sudoku is invalid
- 🎨 Clean UI with smooth animations for solving steps

---

## 🚀 How to use

1️⃣ Open the app in a browser  
2️⃣ Fill the grid with your custom Sudoku puzzle  
3️⃣ Click **"Solve"** to solve the puzzle  
4️⃣ Click **"Reload"** to clear the board  
5️⃣ If the puzzle is invalid (violates Sudoku rules), an error message will appear

---

## 🔧 Technologies used

- **HTML** for structure  
- **CSS** for styling and animations  
- **JavaScript** for Sudoku logic and interactivity
